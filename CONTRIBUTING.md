# Contributing to Awesome Loomly Alternatives

Thanks for helping make this list better! Please follow these guidelines so your pull request can be reviewed quickly.

## Adding a Tool

1. Make sure the tool is a genuine alternative to Loomly (social media scheduling, planning, collaboration, analytics, or management).
2. Check that it isn't already listed.
3. Add it to the **most relevant category** table in `README.md`.
4. Use this format:

   ```markdown
   | **Tool Name** | Best For | [domain.com](https://domain.com) | One short, neutral sentence about what makes it stand out. |
   ```

5. Keep descriptions short (one sentence), factual, and free of marketing hype.
6. Link to the tool's official website only — no affiliate or tracking links.

## Updating or Fixing Entries

- Update outdated links, product names, or descriptions.
- Remove tools that have shut down (please include a source in your PR).
- Typo, grammar, and formatting fixes are always welcome.

## Pull Request Checklist

- [ ] One tool (or one logical change) per pull request.
- [ ] The link works and points to the official site.
- [ ] The entry is in the correct category.
- [ ] The table formatting renders correctly on GitHub.

## Code of Conduct

Be respectful and constructive. By contributing, you agree that your contributions are released under the [CC0-1.0](LICENSE) license.
